figma/components.md, figma/tokens.json, figma/roblox-mapping.md and the style profile. Design
every required screen in Figma (Figma MCP when available) themed to THIS game: frame decor,
title bar pattern, themed close X, open animation. Name layers exactly as the Roblox instances
will be named. If Figma is unavailable, write games/<slug>/figma/ui-spec.md with the same level
of detail and state that UI is blocked on Figma. Never claim a Figma file exists when it doesn't.
