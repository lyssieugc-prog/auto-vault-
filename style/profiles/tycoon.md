# Profile: Tycoon

**Palette**: house palette; each plot's owner color tints buttons/walls. Purchase buttons are
neon green pads (affordable) / red (not affordable).
**Shapes & studs**: studded baseplates per plot, chunky machines (droppers, conveyors, upgraders)
with readable moving parts, blocky buildings that "assemble" with a pop animation on purchase.
**Lighting**: bright daytime; purchases fire a short sparkle + build tween.
**UI deltas**: money counter + income/sec, "next purchase" arrow beam, rebirth progress.
**Map deltas**: 6–8 plots around a shared center (shop, leaderboard, event area). Plot layout
grows outward floor by floor; every button reveals visible geometry.
**Model deltas**: every purchasable is a Blender asset with pre-split "build stages".
**Systems**: Plots, Tycoon, Currency, Upgrades, Rebirth, Monetization, Quests, DataStore.
**Never**: buttons that unlock invisible stats only; buildings built from plain Studio parts.
