# Style Profiles

Each profile **overrides** parts of `style/house-style.md`. Anything a profile does not mention
inherits the house style. Pick exactly one primary profile per game (record it in
`games/<slug>/game.md`); a game may borrow a secondary profile for one zone.

| Profile | Use when the pitch is… |
|---|---|
| `brainrot.md` | meme characters, "steal a …", absurd creatures, Italian-brainrot energy |
| `simulator.md` | click/collect/hatch/upgrade loops, pets, zones, power numbers |
| `tycoon.md` | droppers, conveyors, build-your-business, money-from-machines |
| `obby.md` | parkour, stages, checkpoints, "escape", towers |
| `realistic-building.md` | city/house building, roleplay, furniture, life sim |
| `girly.md` | fashion, dress-up, cafés, cute pets, pastel décor, beauty/salon |

Profile file format: **Palette · Shapes & studs · Lighting · UI deltas · Map deltas · Model
deltas · Audio/VFX mood · Never do**.
