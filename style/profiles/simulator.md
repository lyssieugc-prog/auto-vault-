# Profile: Simulator

**Palette**: house palette; each zone gets its own 2-hue sub-palette + glow accent (forest
green/gold → desert orange/teal → ice blue/white → lava red/yellow → space purple/cyan).
**Shapes & studs**: studded terraced islands, chunky rounded trees/rocks, clickable resource
nodes with oversized silhouettes. Zone gates = big studded arches with lock signs + price.
**Lighting**: bright daytime per zone; ColorCorrection tint per zone on entry.
**UI deltas**: big power/currency counters top-center, egg-hatch overlay with odds strip + pity,
pet inventory grid with equip slots, constant "+1,234" pop-ups.
**Map deltas**: hub spawn → radiating paths → 4–6 zones in a ring/spiral, each 2–5x reward of
the previous. Egg stand per zone. Rebirth statue in hub.
**Model deltas**: pets are many-part blocky creatures with glow eyes; rarer tiers add auras.
**Systems**: Currency, Rarity, Inventory, Upgrades, Rebirth, Quests/Rewards, Monetization,
Tutorial, DataStore, (Trading at launch+1).
**Never**: empty flat zones, unreadable tiny pets, numbers without abbreviation (use 1.2K/3.4M).
