# Profile: Realistic Building / Roleplay

**Overrides the blocky default more than any other profile.**
**Palette**: natural but still slightly saturated (warm wood, brick red, sage, sky blue). UI
stays house-style but with softer panel body `#2A2F3A`.
**Shapes & studs**: cleaner, proportioned architecture; studs only on baseplates/roads, not on
furniture. Still low-poly (bevelled boxes, no sculpted detail).
**Lighting**: Future lighting, day/night cycle allowed, warm interiors.
**UI deltas**: build-mode toolbar (place/rotate/delete/paint), catalog grid with categories,
grid snap toggle, mobile-friendly drag.
**Map deltas**: neighbourhood grid with lots, roads with sidewalks, shops for furniture.
**Model deltas**: furniture kit with consistent scale (1 stud = 0.28m reference), pivot at
bottom-center, collision boxes simplified.
**Systems**: Plots, Inventory (furniture), Currency, Monetization, DataStore (placed builds),
Tutorial.
**Never**: mixing chunky meme props into realistic sets without an explicit exception.
