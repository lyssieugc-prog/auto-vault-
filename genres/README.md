# Genre Profiles (mechanics)

Visual style lives in `style/profiles/`; these files define **loops, systems and content scale**.
`/make-game` picks one primary genre (hybrids: primary + borrowed systems).

| File | Core loop | Default style profile |
|---|---|---|
| `brainrot-steal.md` | buy walking creatures → earn passive income on plot → steal/defend | brainrot |
| `simulator.md` | click/collect → hatch pets → upgrade → unlock zone → rebirth | simulator |
| `tycoon.md` | buy buttons → droppers make money → expand base → rebirth | tycoon |
| `obby.md` | beat stages → checkpoints → coins → skips/cosmetics | obby |
| `building-roleplay.md` | earn → buy furniture/items → build/decorate plot → show off | realistic-building |
| `dress-up.md` | collect outfits → style challenges → rate/vote → unlock | girly |

Every genre file lists: **Loop · Systems (from systems/README.md) · Content scale for v1 ·
Session pacing · Monetization hooks · Required screens · Common pitfalls**.
