# Genre: Simulator

**Loop**: click/collect resource → sell/earn → hatch eggs for pets (multipliers) → upgrades →
unlock next zone (gate cost) → rebirth for permanent multiplier.
**Systems**: Currency, Rarity (eggs + pity), Inventory (pets + equip slots), Upgrades, Rebirth,
Rewards (quests/daily/playtime), Monetization, Tutorial, DataService, Guard, Trading (post-launch).
**Content v1**: 5 zones, 3 eggs/zone, 6–8 pets/egg, index rewards, 10 upgrades.
**Pacing**: first hatch < 60s, new zone every ~10 min early, rebirth at ~40 min.
**Monetization**: x2→x100 ladder, x2 Luck, +equip, auto-collect, auto-hatch, triple hatch, boosts.
**Screens**: all house-required screens + egg hatch overlay + zone gate prompt.
**Pitfalls**: number inflation without abbreviation, zones without new visuals, unrewarding index.
