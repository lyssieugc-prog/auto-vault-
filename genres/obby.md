# Genre: Obby

**Loop**: run stages → checkpoints save progress → coins along the way → cosmetic trails/skips.
**Systems**: Currency (coins), DataService (stage), Rewards, Monetization (skip stage product,
gravity coil, speed coil), Tutorial, Guard (server-validated checkpoint order).
**Content v1**: 50–100 stages in 5–10 themed worlds; reward room every 10 stages.
**Pacing**: stage 1 in < 10s; difficulty ramps gently; a "breather" stage every 5.
**Pitfalls**: client-trusted checkpoints (validate order on server), unfair mobile jumps,
invisible kill parts.
